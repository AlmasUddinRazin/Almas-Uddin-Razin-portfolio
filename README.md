# Portfolio — Syed Almas Uddin Razin

Single-file, dependency-free portfolio site (`index.html`). No build step required.

## Deploy on GitHub Pages
1. Create a new repo (e.g. `razin-portfolio`) or use an existing one.
2. Upload `index.html` to the repo root.
3. Go to **Settings → Pages**, set Source to `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. Your site goes live at `https://<your-username>.github.io/<repo-name>/`.

## Editing
Everything — HTML, CSS, and JS — lives in `index.html`. Content sections (in order):
Hero → Thesis → Business Development track → Esports Operations track →
Achievements band → Parallel timeline → Skills → Certifications/Education → Contact.

Colors, fonts, and spacing are controlled by CSS variables at the top of the `<style>` block.
